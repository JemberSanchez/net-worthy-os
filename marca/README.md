## Cómo obtener los archivos para subir
Abre **`marca/export.html`** en Chrome (doble clic). Cada botón descarga un PNG al tamaño exacto:
- **Avatar** (The Ascending N): `800×800` YouTube · `1080` IG/TikTok/FB · `400` pequeño · versión clara.
- **Ícono/favicon** (The Climb): `512` · `48`.
- **Banner** YouTube: `2048×1152` (wordmark + tagline dentro del área segura).

El SVG fuente de cada marca está embebido en `export.html` (objeto `SVG`), editable a mano.

## Sistema
- **Avatar** = The Ascending N — una N con flecha dorada que sube (net worth ↑). Legible a 48 px.
- **Ícono secundario/favicon** = The Climb — 3 barras ascendentes, la más alta en oro.
- **Wordmark** (banner/headers) = "NET WORTHY" en serif (autoridad) + tagline (confianza).
